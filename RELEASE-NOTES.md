# Sonic Qt Theme Bridge Release Notes

Makes Qt apps fit seamlessly into SonicDE, with your theme, icons, fonts and file dialogs.

## 6.8.2 (2026-11-10)

- Modern apps' toolbars and menu bars now join the window's title bar as one surface, with the theme's opacity and blur, and follow changes to these settings straight away. Themes that don't use this look the same as before.
- Shift+Delete now deletes text in text fields.
- Behind the scenes: removed leftover support for an upstream style that SonicDE doesn't ship, and added the GPL 2.0 or later licence text.

## 6.8.0 (2026-10-20)

- More of the look that apps pick up from the desktop now uses Silver instead of Breeze.
- Behind the scenes: version number update.

## 6.7.5 (2026-09-12)

- Behind the scenes: version number update.

## 6.7.4 (2026-08-03)

No SonicDE-specific changes in this release; it brings the package up to date with upstream.

## 6.7.3.2 (2026-08-04)

- More of the look that apps pick up from the desktop now uses Silver instead of Breeze.

## 6.7.3.1 (2026-08-01)

- Apps now use SonicDE's own Silver theme as their base and default look instead of Breeze.

## 6.7.3 (2026-07-21)

- Streamlined for SonicDE: Wayland and old Qt 5 support have been removed.
- Behind the scenes: improved code formatting and developer tooling.
